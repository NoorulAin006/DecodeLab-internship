# Cybersecurity System Audit

## Overview

The **Cybersecurity System Audit** project evaluates the security posture of a Windows-based computer by performing a structured security assessment. The audit identifies security strengths, weaknesses, and potential risks while providing recommendations to improve the overall protection of the system.

The project follows standard cybersecurity auditing practices, including the inspection of operating system security settings, update status, installed applications, storage encryption, account security, antivirus protection, and firewall configuration.

---

## Objectives

* Assess the security configuration of a Windows system.
* Identify security risks and vulnerabilities.
* Verify compliance with basic cybersecurity best practices.
* Recommend improvements to strengthen system security.
* Document audit findings with supporting evidence.

---

## Scope

The audit covers the following areas:

* Windows Update
* Microsoft Defender Antivirus
* Windows Firewall
* User Account Control (UAC)
* Installed Applications Review
* Startup Applications
* BitLocker Drive Encryption
* User Accounts and Password Security
* Multi-Factor Authentication (MFA)
* Windows Security Features
* General System Configuration

---

## Audit Methodology

The system audit was conducted using the following steps:

1. Review Windows Security settings.
2. Verify Windows Update status.
3. Inspect installed applications.
4. Review startup programs.
5. Check Microsoft Defender Antivirus.
6. Verify Windows Firewall configuration.
7. Examine User Account Control settings.
8. Check BitLocker encryption status.
9. Review user accounts and authentication settings.
10. Record findings and recommend improvements.

## Audit Findings

### Strengths

* Windows Defender enabled.
* Windows Firewall enabled.
* Operating system fully updated.
* Most installed applications are recognized and legitimate.
* Startup applications reviewed.
* User account protected with password authentication.
* User Account Control configured to notify before changes.

### Weaknesses

* Multi-Factor Authentication (MFA) disabled on online accounts.
* BitLocker drive encryption not enabled.
* Several startup applications may slightly impact boot performance.
* Unknown executable files require further verification.

---

## Recommendations

* Enable BitLocker drive encryption.
* Enable Multi-Factor Authentication for all important accounts.
* Remove unnecessary startup applications.
* Delete unused software.
* Keep Windows and applications updated.
* Perform regular antivirus scans.
* Backup important data regularly.
* Avoid downloading software from untrusted sources.

## Conclusion

The cybersecurity audit showed that the system has a solid baseline security configuration with Windows Defender, Firewall, and Windows Updates properly configured. However, improvements such as enabling BitLocker encryption and Multi-Factor Authentication would significantly increase the overall security posture. Regular maintenance, software updates, and periodic security audits are recommended to maintain a secure computing environment.
