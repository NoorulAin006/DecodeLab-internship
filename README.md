## 🔐 Task 1 – Password Strength Checker

### 📌 Overview
The Password Strength Checker is a Python-based application designed to evaluate password security based on common cybersecurity standards.

It analyzes passwords using multiple security criteria and provides feedback to help users create stronger and more secure passwords.

### 🎯 Objectives
- Understand password security concepts.
- Identify weak password patterns.
- Promote secure password creation practices.
- Implement password validation logic using Python.

### ✨ Features
- Checks minimum password length.
- Detects uppercase letters.
- Detects lowercase letters.
- Detects numeric digits.
- Detects special characters.
- Classifies passwords as:
  - Weak
  - Medium
  - Strong
- Provides improvement suggestions.

### 🛠 Technologies Used
- Python 3
- Visual Studio Code

### 📚 Concepts Used
- Variables
- User Input
- Conditional Statements
- Loops
- Functions
- String Operations

🖥️ Task 4 – Cybersecurity System Audit
📌 Overview

The Cybersecurity System Audit project evaluates the security posture of a Windows-based system.

The audit was performed by reviewing security configurations, system protection features, authentication settings, installed applications, and cybersecurity best practices.

🎯 Objectives
Assess Windows security configuration.
Identify possible security weaknesses.
Verify security best practices.
Document findings and recommendations.
🔍 Audit Areas

The audit covered:

Windows Update
Microsoft Defender Antivirus
Windows Firewall
User Account Control (UAC)
Installed Applications Review
Startup Applications
BitLocker Encryption
Password Security
Multi-Factor Authentication (MFA)
Windows Security Features
🛠 Tools Used
Windows 10
Windows Security
Microsoft Defender Antivirus
Windows Defender Firewall
Windows Update
Control Panel
Settings Application
Task Manager
File Explorer
✅ Audit Findings
Strengths

✔ Windows Defender enabled
✔ Windows Firewall enabled
✔ System updates installed
✔ Applications reviewed
✔ Password authentication enabled
✔ User Account Control configured

Weaknesses

⚠ Multi-Factor Authentication disabled
⚠ BitLocker encryption disabled
⚠ Some startup applications affect performance
⚠ Unknown executable files require verification

🔧 Recommendations
Enable BitLocker encryption.
Enable MFA on important accounts.
Remove unnecessary startup applications.
Delete unused software.
Perform regular security scans.
Keep applications updated.
Maintain regular backups.
Avoid untrusted downloads.
