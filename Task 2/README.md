# Basic Encryption and Decryption

## Description
This project implements a basic encryption and decryption system using Python.
It allows users to convert normal text into an encrypted form and decrypt it back
to the original message.

## Features
- Encrypt text messages
- Decrypt encrypted messages
- Simple command-line interface
- User-friendly input and output

## Technologies Used
- Python

## How to Run

1. Install Python.
2. Open the project folder.
3. Run:
python "Basic Encryption Decryption.py"

## Learning Outcomes
- Understanding encryption and decryption concepts
- Working with strings in Python
- Improving Python programming skills
