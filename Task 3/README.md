# Project 3 – Phishing Awareness Analysis

## Overview

This project focuses on identifying and analyzing phishing emails to understand how cybercriminals use social engineering techniques to deceive users. Three sample phishing emails were examined to identify suspicious indicators, assess potential risks, and recommend appropriate security measures.

## Objectives

* Analyze phishing email samples.
* Identify phishing indicators and red flags.
* Explain why each email is potentially unsafe.
* Assess the possible security risks.
* Recommend best practices for preventing phishing attacks.

## Project Contents

* Phishing Email 1 Analysis
* Phishing Email 2 Analysis
* Phishing Email 3 Analysis
* Risk Assessments
* Security Recommendations

## Skills Demonstrated

* Phishing Detection
* Email Security Analysis
* Social Engineering Awareness
* Threat Assessment
* Cybersecurity Reporting
* Risk Analysis

## Tools Used

* Microsoft Word
* PDF

## Learning Outcomes

This project enhanced my ability to identify phishing attacks by analyzing suspicious sender addresses, deceptive domains, misleading branding, psychological manipulation techniques, and malicious calls to action. It also strengthened my understanding of cybersecurity best practices for protecting users against email-based threats.
